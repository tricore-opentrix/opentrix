## Kiểm chứng và bàn giao

1. Mở Draft PR tài liệu, ghi `Refs #112`, dẫn baseline và bảng trên. Khi chuyển file từ PR cũ, ghi PR/SHA/path nguồn, thay đổi đã chọn và các phần còn thiếu xác minh về nguồn gốc hoặc NOTICE.
2. Trên SHA triển khai, chạy test hợp đồng lỗi và input. Ví dụ từ `backend/`: `./gradlew test --tests '*HelpdeskErrorContractTest' --rerun-tasks` (Windows dùng `gradlew.bat`). Chạy test HTTP/PostgreSQL bằng môi trường disposable theo [runbook](https://github.com/tricore-opentrix/opentrix/blob/187dbd2ea6935966f5c4cceb95ad9c3c53708a2e/scripts/README-helpdesk-local.md#L98). Test PostgreSQL có điều kiện `HELPDESK_DISPOSABLE_URL`; kiểm tra báo cáo skip trước khi ghi PASS. [T:60](https://github.com/tricore-opentrix/opentrix/blob/187dbd2ea6935966f5c4cceb95ad9c3c53708a2e/backend/src/test/java/com/tricore/dxos/infrastructure/workflow/HelpdeskHttpPostgresTest.java#L60)
3. Chạy test docs mặc định tắt và loopback safety. Trên profile local đã kiểm, export spec runtime và so chính xác 9 cặp method/path, response schema, các trường nullable/optional, auth và lỗi. Lưu SHA, lệnh, phiên bản, log đã bỏ dữ liệu nhạy cảm, SHA-256 của spec và kết quả kiểm UTF-8.
4. Chuẩn bị spec tĩnh đã làm sạch và hướng dẫn tích hợp có ví dụ tái lập. Giữ Swagger runtime trong phạm vi local. Đưa bằng chứng và bản diff cho reviewer độc lập trước khi chốt #112.
