## 2. Tóm tắt / Summary

**VI:** Tại baseline, mã nguồn có Workflow state machine tự phát triển (không phải Flowable), Identity/Data contracts, JWT security và Backend Helpdesk dùng PostgreSQL. Backend theo hướng Spring Boot Modular Monolith; Flowable chỉ là phương án đang được Block A đánh giá, chưa được phê duyệt tích hợp. CI thành công trên đúng SHA nhưng không xác lập PostgreSQL/Keycloak runtime tích hợp. `PostgresWorkflowPersistence` có `@Component`; bootstrap/health chưa được chạy trong lần kiểm kê này. Object storage chưa có production adapter; tài liệu tại baseline chọn MinIO, nhưng #26 sau đó đóng và #181 yêu cầu đổi hướng (provider thay thế còn `UNKNOWN`). Spring MVC/Security và Portal BFF đã có một phần chức năng API Gateway; gateway chuyên dụng chưa có bằng chứng runtime và APISIX không phải vendor bắt buộc. R23/REUSE kiểm metadata/policy; #138 và R24 release acceptance vẫn độc lập. Lỗi newline LF/CRLF R24 trên Windows là kết quả owner-reported, không phải phán quyết release.

**EN:** At the pinned baseline, source includes an in-house Workflow state machine (not Flowable), Identity/Data contracts, JWT security and PostgreSQL-backed Helpdesk. Spring Boot Modular Monolith is the backend direction; Flowable is an unapproved option under Block A review, not an integrated engine. CI passed at the exact SHA but does not establish PostgreSQL/Keycloak runtime integration. `PostgresWorkflowPersistence` has `@Component`; startup/health were not exercised. Object storage lacks a production adapter; baseline docs selected MinIO, while later #26/#181 request a direction change with replacement still `UNKNOWN`. Spring MVC/Security and the Portal BFF implement part of the Gateway boundary; no dedicated gateway runtime is verified, and APISIX is not mandatory by vendor name. R23/REUSE metadata checks do not replace #138 rights or R24 release acceptance. Reported Windows newline failures are not a release verdict.
