## 2. Tóm tắt / Summary

**VI:** Baseline có React Portal ở chế độ MOCK và cấu hình `integration-local`, cùng mã BFF cho phiên OIDC, CSRF và chuyển tiếp Helpdesk. Golden Path có test cấp backend, còn bằng chứng browser với Keycloak/BFF thật tại baseline chưa được xác nhận. Facility hiện có fixture MOCK ở frontend và placeholder ở backend. Kiểm chứng Facility hoãn đến sau hạn nộp để ưu tiên Helpdesk Golden Path. Hai PR R29/R33 đã đóng chưa merge và được dẫn làm lịch sử. Khi công bố kết quả, cần gắn từng tuyên bố với chế độ chạy, SHA và loại bằng chứng.

**EN:** The baseline contains a React MOCK portal, a separate local integration mode, and BFF code for OIDC sessions, CSRF and Helpdesk forwarding. Backend Golden Path test code exists, while exact-baseline Keycloak/BFF browser execution has not been established. Facility has frontend MOCK fixtures and a backend placeholder. Facility verification is deferred until after submission so that the Helpdesk Golden Path takes priority. The closed and unmerged R29/R33 PRs are historical references.
