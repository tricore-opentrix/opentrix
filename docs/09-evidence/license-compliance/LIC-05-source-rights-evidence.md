## Contributor declaration process

1. Complete the PR template in first person, identifying files and actual contributed lines/hunks. Separate creation, prompting, editing, integration and review-only work.
2. Identify original/adapted/vendored/generated/AI-assisted portions and actual source URLs/licenses/assets/dependencies. For AI-assisted work, identify supplied inputs and reviewed output where known; AI use is not proof of origin or permission.
3. State the authority you actually have to license your own portions. Do not attest for another contributor, upstream owner or unknown template. Explicitly list UNKNOWN/NOT_RECALLED/permission gaps.
4. Link the declaration section via the PR URL or a permalinking contributor comment. A coordinator may index the statement but must not impersonate the contributor or manufacture a signature/date.
5. Route independent per-portion review using the canonical gates. Record reviewer, exact source SHA, portion, actual review link and unresolved findings. All checkbox/declaration evidence remains insufficient by itself for CLEARED.
6. Resolve source-rights dispositions only in separately authorized canonical work with genuine evidence. Keep #138 OPEN and R24 BLOCKED until their criteria are met.
